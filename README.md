## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3 (Estilos personalizados con Glassmorphism), JavaScript (ES6+).
* **Base de Datos & Backend:** Supabase (PostgreSQL, Realtime API).
* **Control de Versiones:** Git & GitHub.
* **IDE:** Visual Studio Code.

## ⚙️ Características Implementadas (MVP)
1. **CRUD Completo:**
   * **Crear:** Registro de nuevas solicitudes con validación.
   * **Listar:** Visualización dinámica desde Supabase en orden cronológico.
   * **Editar:** Modificación instantánea de registros existentes.
   * **Eliminar:** Borrado seguro con confirmación.
2. **Búsqueda / Filtro:** Filtrado en tiempo real en el frontend.
3. **Diseño Responsivo:** Interfaz adaptada a ordenadores y teléfonos móviles.
